# Tabs Design System

A `Tabs` component with an optional `Badge` on each tab, built on a small token
layer shared between components and docs.

## How this is organised

- **Foundations**: colors, typography and spacing, generated from the same
  token source the components consume. See
  [Colors](?path=/docs/foundations-colors--docs),
  [Typography](?path=/docs/foundations-typography--docs) and
  [Spacing](?path=/docs/foundations-spacing--docs).
- **Components**: [Tabs](?path=/docs/components-tabs--docs) and
  [Badge](?path=/docs/components-badge--docs), with playgrounds and usage
  notes.

## Usage

```tsx
import { Tab, TabList, TabPanel, Tabs } from "fe-interview-design-system";

<Tabs defaultValue="emails">
  <TabList aria-label="Inbox">
    <Tab value="emails">Emails</Tab>
    <Tab value="files" badge={{ label: "Warning", variant: "negative" }}>
      Files
    </Tab>
  </TabList>
  <TabPanel value="emails">Emails content</TabPanel>
  <TabPanel value="files">Files content</TabPanel>
</Tabs>
```

## Accessibility

Tabs follow the WAI-ARIA APG tabs pattern, with keyboard support and
automatic activation built in by default.
