# Tabs Design System

A `Tabs` component with an optional `Badge` on each tab, styled with CSS
custom properties from a small token layer.

See [Tabs](?path=/docs/components-tabs--docs) and
[Badge](?path=/docs/components-badge--docs) for playgrounds and usage notes.

## Usage

The package is not published; its public entry point is `src/index.ts`.

```tsx
import { Tab, TabList, TabPanel, Tabs } from "fe-interview-design-system";

<Tabs defaultValue="emails">
  <TabList aria-label="Inbox">
    <Tab value="emails" label="Emails" />
    <Tab value="files" label="Files" badge={{ label: "Warning", variant: "negative" }} />
  </TabList>
  <TabPanel value="emails">Emails content</TabPanel>
  <TabPanel value="files">Files content</TabPanel>
</Tabs>
```

## Accessibility

Tabs follow the WAI-ARIA APG tabs pattern, with keyboard support and
automatic activation built in by default.
